# Paper figures (PDF)

Publication plots from `src/eval_pub.ipynb` are written here as **vector PDFs** when `SAVE_FIGURES=True`.

- Path: `<repo>/figures/paper/` (next to `src/`)
- Naming: `01_<stem>.pdf`, `02_<stem>.pdf`, …
- Shared helper for scripts: `plot_utils.save_figure_pdf`

Re-run the notebook (section 1 + figure cells) to regenerate.
